Troubleshooting
Problem	Solution
ollama: command not found	Ollama not installed or not in PATH. Install from ollama.com
Connection refused on localhost:11434	Ollama isn't running. Run ollama serve first
ModuleNotFoundError	Run pip install -e . in the project folder
Port 7860 already in use	Close another instance of the app, or change the port in app.py
No chunks from PDF	Make sure the PDF has a digital text layer (not just scanned images)
To stop the app
Press Ctrl+C in the terminal where python app.py is running.

That's it — once Ollama is running and dependencies are installed, python app.py is all you need to launch the chatbot.
